# DojoMeeting

## DojoMeeting とは

DojoMeetingは、CoderDojoに関心のある人たちが、気軽につながり、情報交換を楽しむ場です。

地域のCoderDojoをもっと盛り上げるために、運営の悩みを相談したり、「こんなことをやってみたら良かったよ！」という事例を共有したり、新しいツールを紹介したり。CoderDojoにまつわることを自由に話し合いましょう。

話してみたい話題は、[GitHubのIssue](https://github.com/kwaka1208/DojoMeeting/issues/new/choose) で募集しています。

開催案内には [DojoMeeting - connpass](https://dojo-meeting.connpass.com/) も使えます。

```
提案された話題は必ず取り上げられることが保証されていません。提案されていない話題を自由に話してもOKです。

connpassの利用も必須ではなく使いたい方がいらっしゃったらどうぞ、という感じです。
```

**開催場所も、形式も自由です！**

オンラインでもオフラインでも、カフェで集まっても、飲み会形式でもOK。決まったルールや形式はありません。誰でも、どこでも、気軽に開催できます。

## こんな方はぜひ！

- CoderDojoのチャンピオン、メンター、ボランティアの方
- CoderDojoに参加している子どもや保護者の方
- CoderDojoに興味がある方、これから始めてみたい方
- CoderDojoには参加していないけれど、活動に関心がある方

**CoderDojoに参加しているどうかは問いません。** 興味や関心があれば、どなたでも大歓迎です。年齢も問いません。

## 開催してみませんか？

DojoMeetingは、誰かが企画したイベントに参加するだけのものではありません。

- 近くのチャンピオン同士で情報交換したい
- CoderDojoに興味がある人たちで集まってみたい
- オンラインでちょっと話してみたい
- たまには飲みながら情報交換したい

そんな気軽なきっかけで十分です。

このリポジトリの管理者に限らず、各地域のCoderDojoを運営している方も、このページを活用して、それぞれの地域でDojoMeetingを開催していただいて構いません。

開催告知、参加者募集用に [DojoMeeting - connpass](https://dojo-meeting.connpass.com/) を使っていただいて結構ですので、ご希望の方は、connpassのアカウントを[GitHubのIssue](https://github.com/kwaka1208/DojoMeeting/issues/new/choose)からお知らせください。

**まずは気軽に集まって、話してみませんか？**
